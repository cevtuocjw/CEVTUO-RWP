Installation

macOS

  1. Open the .dmg and drag CEVTUO-RWP2EPUB into Applications.
    打开 .dmg,把 CEVTUO-RWP2EPUB 拖进「应用程序」。
  2. First launch: right-click the app → Open.
    首次打开:右键点 App → 打开。
  3. On macOS 15 Sequoia and later, the right-click shortcut no longer works. Do this instead:
    • Double-click the app. When the “Apple could not verify…” dialog appears, click Done.
    • Open System Settings → Privacy & Security.
    • Scroll down to the Security section. You will see “…was blocked from use”. Click Open Anyway.
    • Enter your password or use Touch ID, then confirm once more.
    新版 macOS(15 Sequoia 及以后):先双击 App,弹出“Apple 无法验证…”提示,点“完成”。
    打开 系统设置 → 隐私与安全性,往下滚到“安全性”区域,会看到“已阻止使用…”,点 仍要打开。
    输入密码或 Touch ID,再确认一次。

⊞ Windows

  1. Unzip CEVTUO-RWP2EPUB-windows.zip.
    解压 CEVTUO-RWP2EPUB-windows.zip。
  2. Open the extracted CEVTUO-RWP2EPUB folder.
    进入解压出来的 CEVTUO-RWP2EPUB 文件夹。
  3. Double-click CEVTUO-RWP2EPUB.cmd — this is what launches the app.
    双击 CEVTUO-RWP2EPUB.cmd —— 这就是启动入口。
  4. If Windows shows “Windows protected your PC”, click More info → Run anyway.
    若弹出“Windows 已保护你的电脑”,点 更多信息 → 仍要运行。

A window opens by itself. No Python, no dependencies to install — the runtime ships inside the zip. 会自己弹出一个独立窗口。不需要装 Python,不需要装任何依赖,运行时都在压缩包里。

Four ways in

Multiple URLs, links found on a site, RSS feeds, or Markdown. Every article becomes a chapter you can open and edit on its own.

Real full text

Pages are rendered in your own browser before extraction, so JavaScript-only content and archived pages come through complete.

Daily books from RSS

Build a book per category automatically, on a daily or every-few-days schedule, filed by date in the library.

No page limit

Export as many chapters as you like. Nothing gets truncated.

Runtime included

The Python runtime and every dependency ship inside the installer. The target machine needs nothing installed.

Library wherever you want

Point the library folder anywhere; books you already generated move along with it.
