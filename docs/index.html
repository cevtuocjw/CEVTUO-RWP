CEVTUO-RWP2EPUB

把网页、网站内链接、RSS 订阅和 Markdown 做成 EPUB 电子书。
原生桌面应用,自带运行时,下载即用。

author: cevtuo

下载 macOS 版.dmg · Apple Silicon · 约 100 MB ⊞ 下载 Windows 版.zip · Windows 10/11 · 约 100 MB
大陆网络直连 GitHub 可能很慢,可用下面的加速镜像(内容与官方完全相同)
macOS · ghproxy.net macOS · gh-proxy.com macOS · ghfast.top Windows · ghproxy.net

macOS 首次打开请右键 → 打开(ad-hoc 签名,未经 Apple 公证)
镜像为第三方公共转发服务,只是把 GitHub 的流量中转一下;介意的话请用上面官方直连

多条路都能成书

多个网址、网站内链接、RSS 订阅、Markdown —— 每篇文章就是一个章节,可单独查看与编辑。

真正的全文

用你自己的浏览器渲染页面再取正文,靠 JavaScript 才显示的内容、存档站页面都能拿到完整全文。

RSS 每日成书

按分类自动成书,可设每天 / 每隔两三天定时生成,书库里按日期归档。

没有页数限制

导出多少章都可以,不做任何截断。

自带运行环境

Python 运行时与全部依赖都在安装包里,目标机器不需要装任何东西。

书库位置随你放

可以改书库文件夹,已有的书会跟着一起搬过去。
