CEVTUO-RWP — Windows
=========================

怎么启动
--------
这个包没有 .exe 安装程序,也不需要安装。启动入口是:

    CEVTUO-RWP.cmd      ← 双击这一个文件

1. 解压 CEVTUO-RWP-windows.zip
2. 进入解压出来的 CEVTUO-RWP 文件夹
3. 双击 CEVTUO-RWP.cmd

会自己弹出一个独立窗口(用系统自带 Edge 的 app 模式,没有地址栏)。
不需要安装 Python,不需要装任何依赖 —— 运行时都在这个文件夹里。

⚠ 整个文件夹要放在一起。CEVTUO-RWP.cmd 需要它旁边的 python\ 和 pylibs\,
  单独把 .cmd 拷到别处是用不了的。

想放桌面:右键 CEVTUO-RWP.cmd → 发送到 → 桌面快捷方式

如果弹出「Windows 已保护你的电脑」
---------------------------------
这是 SmartScreen 对从网上下载的脚本的例行提示,不是病毒警告。
点「更多信息」→「仍要运行」即可。

怎么关掉
--------
关掉窗口后,本地服务仍在后台运行(所以再次打开是秒开)。
它只监听 127.0.0.1,不会把任何东西发到外面。
要彻底关掉,双击:

    停止服务.cmd

环境要求
--------
- Windows 10 / 11 (x64)
- 渲染网页需要一个 Chromium 内核的浏览器。Windows 10/11 自带 Edge,通常无需额外安装。

数据保存在哪
------------
%LOCALAPPDATA%\CEVTUO-RWP
里面有 output/(每日书)、books/(合集导出)、history/、state/、logs/。

已知限制
--------
- 定时自动生成功能在 Windows 版暂不可用(需要另接计划任务)。
  界面上的「一键生成」正常可用。
- 本安装包未在真实 Windows 机器上测试过,如有问题请提 Issue。
